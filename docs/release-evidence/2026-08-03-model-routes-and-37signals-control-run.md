# Проверка модельных маршрутов и контрольный прогон 37signals — 2026-08-03

## Что проверялось

- реальные HTTP-endpoint AgentRouter и ZenMux/DeepSeek;
- production-маршрут Gemini через американский proxy;
- полный пользовательский путь `session -> project -> trial -> worker -> version`;
- открытие виджета, desktop/mobile preview и реальный ответ preview-чата во
  встроенном браузере Codex.

## Состояние провайдеров

### AgentRouter

Документация и реализация Kaigo совпадают:

- Base URL: `https://co.agentrouter.org/v1`;
- протокол: OpenAI Chat Completions;
- модели: `gpt-5.5` и `glm-5.2`.

Один и тот же production-ключ проверен с нидерландского и американского
серверов, с Bearer-заголовком и альтернативным `x-api-key`. Во всех случаях
официальный endpoint вернул `401 Invalid API Key`. Старый endpoint
`https://agentrouter.org/v1` также вернул `401 unauthorized_client`. Это
исключает ошибку endpoint, wire format, туннеля и географического IP; для
возврата GPT/GLM нужен новый действующий ключ AgentRouter.

### ZenMux / DeepSeek V4 Flash Free

- Base URL: `https://zenmux.ai/api/v1`;
- модель: `deepseek/deepseek-v4-flash-free`;
- `/models` отвечает и содержит нужную модель;
- Chat Completions и Responses API возвращают `402 reject_no_credit`.

Ответ ZenMux прямо указывает, что бесплатная модель доступна только аккаунтам с
положительным балансом. Это антиабуз-ограничение, а не списание за саму free
модель. После любого положительного пополнения текущий адаптер Kaigo можно
включить без изменения endpoint или model slug.

### Gemini

Новый free-tier ключ проверен через действующий US proxy:

- structured text на `gemini-3.6-flash` — успешно;
- structured vision с изображением — успешно;
- preview-чат на `gemini-3.5-flash-lite` — успешно.

Пока два внешних текстовых маршрута заблокированы аккаунтами, production
оставлен на стабильном Gemini-маршруте. Ключи AgentRouter и ZenMux сохранены в
конфигурации, но гибридный флаг выключен, чтобы каждый этап не тратил время на
заведомые `401/402`.

latency `23 557 мс`. Ответ корректен, но такая задержка слишком велика для
посетительского чата и должна стать первой задачей оптимизации.

## Замечание к тестовому harness

Первоначальный служебный brief прошёл через PowerShell/SSH pipe с неверной
кодировкой и сохранился как `????`. Это не воспроизводится в браузерной форме и
не является дефектом хранения Kaigo. Отображаемый brief тестового проекта после
прогона восстановлен UTF-8-безопасным способом. Сам run остаётся честным
доказательством анализа сайта, сборки, визуальной проверки и chat bridge, но не
используется как доказательство точного следования тому служебному brief.
