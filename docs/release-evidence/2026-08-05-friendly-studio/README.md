# Одноэкранная Studio — доказательства релиза

Дата: 2026-08-05

Ветка: `codex/product-ui`

Базовый commit интерфейса: `cc69735` (`feat: rebuild Studio as a single-screen AI workspace`); финальная проверка также включает исправление переполнения панели публикации.

## Результат

Studio перестроена в одно рабочее пространство без прокрутки всей страницы:
слева расположен чат с Kaigo, этапы и поле доработки, справа — большой живой
предпросмотр. Контекст проекта сворачивается, а проекты, история версий и
публикация открываются в отдельных боковых панелях поверх рабочего экрана.

На узких экранах чат и предпросмотр переключаются двумя явными вкладками. Сам
предпросмотр по-прежнему можно проверить в desktop- и mobile-размере.

## Автоматическая проверка

Команды запускались из `frontend/` после финальных исправлений:

| Команда | Результат |
| --- | --- |
| `npm test -- --run` | 24 файла, 217 тестов прошли |
| `npm run lint` | без предупреждений |
| `npm run typecheck` | прошёл |
| `npm run build` | production-сборка прошла |
| `npm run test:e2e` | 14 из 14 сценариев прошли |

Browser-набор проверяет создание и восстановление проекта, отмену и повтор,
публикацию активной версии, мобильные вкладки, отсутствие переполнения,
`prefers-reduced-motion` и отсутствие серьёзных/критических axe-нарушений.

## Проверка публичного preview

Изолированный preview обновлён до `cc69735` и открыт в реальном Chromium на
1920 × 1080 и 390 × 844.

- Основная Studio, проекты, версии и публикация открылись без ошибок.
- На мобильном экране вкладки чата и предпросмотра работают отдельно.
- У документа нет горизонтальной или вертикальной прокрутки; прокручивается
  только содержимое рабочей области, когда это необходимо.
- В консоли браузера нет ошибок и предупреждений.
- Страница, сессия и проект отвечают HTTP 200; изолированный API-сервис активен.

## Ограничения и безопасность

- Данные preview, подписка и публикация принадлежат изолированной fixture, а не
  реальному клиентскому проекту.
- Не запускались платная генерация, оплата, отправка писем или реальная
  публикация внешнего виджета.
- Production checkout, production-сервисы, nginx и миграции не изменялись.
- [`capture-evidence.mjs`](./capture-evidence.mjs) воспроизводит кадры локально с
  той же изолированной fixture.
