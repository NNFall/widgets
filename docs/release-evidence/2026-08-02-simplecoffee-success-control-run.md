недостаточно заметно реагировала на состояние ожидания. Модель исправила
анимацию с первой попытки, после чего повторная техническая и браузерная
проверки прошли. Три AI-критика не сформировали валидный итоговый контракт,
поэтому сработал новый безопасный режим: подтверждённый браузером рабочий
результат сохранился, а отсутствие формального AI-отчёта осталось предупреждением.
