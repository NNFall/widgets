# Команда просмотра предыдущего поста в Telegram-боте

## Цель

Добавить владельцу канала команду `/previous` с алиасом `/lastpost`. Команда
показывает в личном чате с ботом последний пост, опубликованный в `@kaigoww`, не
создавая новую публикацию и не запуская ход Codex.

## Выбранный подход

Бот читает последний `record_type=post` из `docs/telegram/published.jsonl` и
вызывает Telegram Bot API `copyMessage` для записанного message ID. Telegram сам
сохраняет форматирование, фотографию, подпись и остальные поддерживаемые типы
вложения. Это надёжнее, чем заново собирать публикацию из локального HTML и
медиафайлов.

Реестр поддерживает как текущее поле `telegram_message_id`, так и будущее
`telegram_message_ids`. Второй вариант нужен для альбомов: бот копирует каждый
элемент группы в исходном порядке.

## Компоненты

- `PublishedPostHistory` читает JSONL по запросу и возвращает ID последней
  публикации. Файл не кешируется, поэтому новая запись становится доступна без
  перезапуска бота.
- `TelegramClient.copy_message` вызывает `copyMessage` с целевым личным чатом,
  каналом-источником и message ID.
- `BridgeService` обрабатывает `/previous` и `/lastpost` до очереди Codex.
- Конфигурация получает `publication_channel` и `published_registry_path`.

## Ошибки

- Если история публикаций не настроена или в ней нет постов, бот объясняет это
  по-русски.
- Повреждённая строка JSONL не ломает мост: история пропускает её и ищет
  предыдущую валидную запись.
- Если Telegram не может скопировать удалённое или недоступное сообщение, бот
  сообщает, что предыдущий пост сейчас недоступен, и помечает команду
  обработанной, чтобы не зациклить polling.

## Проверка

1. Unit-тест истории: одиночный пост, альбом, повреждённая строка и пустой
   реестр.
2. Unit-тест API-клиента: точный контракт `copyMessage`.
3. Unit-тест сервиса: команда копирует все ID по порядку и не вызывает Codex.
4. Полный набор тестов моста и `compileall`.
5. Живая команда `/previous` в личном чате владельца после перезапуска Scheduled
   Task. Публичный канал при этом не изменяется.

## Вне задачи

- Загрузка входящих фотографий из личного чата в Codex.
- Редактирование или удаление публикаций.
- Автоматическая публикация без явного одобрения.
