# Черновики Telegram

Один файл соответствует одной публикации. Имя:
`YYYY-MM-DD-kebab-case-topic.md`.

Статусы:

- `draft` — рабочая версия;
- `review` — готова к проверке владельцем;
- `approved` — текст утверждён, но ещё не опубликован;
- `published` — опубликован и занесён в `../published.jsonl`;
- `hold` — отложен из-за неподтверждённого факта или отсутствующего материала.

Черновик не является разрешением на публикацию. Telegram-редактор не должен
отправлять его во внешний канал без отдельного явного указания пользователя.
