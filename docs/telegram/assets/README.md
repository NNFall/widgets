## Требования

- Использовать только реальные скриншоты Kaigo и исследуемого публичного сайта.
- Не сохранять ключи, пароли, SSH-реквизиты, внутренние IP и персональные данные.
- Кадрировать лишние вкладки, адресную строку и технический шум, если они не
  являются частью сюжета.
- Рядом с изображениями добавлять `README.md` с датой, источником, run ID и
  кратким описанием каждого кадра.
- Не заменять фактический результат сгенерированной иллюстрацией.
