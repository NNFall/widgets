который прошёл перед публикацией. После активации публичная `v10` дополнительно
проверена в Chromium при 390 × 844: ширина документа равна ширине viewport,
ошибок страницы нет. На кадрах отсутствуют ключи, SSH-реквизиты и приватные
production-данные.
