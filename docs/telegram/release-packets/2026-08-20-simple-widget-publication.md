# Публикация виджета без ручной настройки домена

Дата: 2026-08-20
Статус: выпущено в production, live marketing release `476f6c1`.

## Коротко

Путь от готового виджета до установки стал короче. Пользователь нажимает
«Опубликовать и получить код», а после публикации получает отдельно скрипт для
сайта, прямую ссылку загрузчика и переход к подробной инструкции.

## Что изменилось

- Поле домена убрано из клиентского интерфейса публикации.
- При первой публикации система сама получает точный HTTPS origin из исходной
  ссылки проекта.
- После публикации доступны два самостоятельных действия: скопировать скрипт
  установки или скопировать прямую ссылку загрузчика. Для каждого
  действия интерфейс показывает отдельное подтверждение.
- Ссылка `/install` открывает подробную инструкцию по подключению.
- Восстановление существующей публикации работает fail-closed. Если настройки
  не загрузились, интерфейс не включает публикацию по запасному флагу и просит
  перезагрузить страницу.
- Если системный Clipboard API недоступен или отклонил запрос, оба значения
  остаются видимыми и доступными для ручного копирования.

## Проверка production

- Страница `/install` проверена при viewport desktop 1920 × 1080 и mobile
  390 × 844. Горизонтального переполнения нет.
- На странице инструкции есть пять разделов: HTML, Tilda, WordPress, Webflow и
  Wix/другие платформы.
- На внешнем 37signals-canary закрытая кнопка проверена в размере 64 × 64.
  Открытая панель занимает 402 × 438 на desktop и 340 × 438 на mobile.
- Закрытие виджета и повторное открытие проверены на живой странице.

## Техническая проверка

- frontend: 289 тестов;
- backend: 5 тестов;
- nginx: 2 теста;
- typecheck, lint и production build прошли;
- финальное независимое review: GO.

## Безопасность

Автоматизация не превращает публикацию в режим «разрешить везде»: для первой
публикации сохраняется точный HTTPS origin исходного сайта. При ошибке
восстановления интерфейс останавливает действие и предлагает перезагрузить
страницу. В редакторские материалы не включены пользовательские данные,
инфраструктурные адреса, ключи или закрытые проверочные ссылки.

## Ограничение

Автоматически используется адрес исходного проекта. Если виджет нужно поставить
на другой сайт, список разрешённых адресов потребуется изменить отдельно.

## Возможный сюжет

Раньше перед публикацией мы спрашивали у пользователя техническую деталь — на
каком домене будет стоять виджет. Но адрес уже был в исходной ссылке проекта.
Теперь достаточно одной кнопки: Kaigo сохраняет точный адрес, публикует виджет и
сразу отдаёт два понятных результата — код для сайта и прямую ссылку
загрузчика.
