# Доработки больше не исчезают из чата Kaigo

Дата: 2026-08-21

Статус: реализовано и проверено локально; production deployment не выполнялся.

## Коротко

Studio теперь показывает каждую доработку как понятный разговор. Сначала виден
точный запрос владельца сайта, во время работы — текущий публичный этап, а после
завершения — «Готово — версия N» и конкретное описание результата. После
перезагрузки страницы история не исчезает.

Одновременно исправлен mobile preview. Исходный экран виджета 390 × 844 теперь
масштабируется и по ширине, и по доступной высоте Studio. Устройство, iframe и
canvas полностью остаются в одном фиксированном экране даже на 320 × 568.

## Что изменилось для пользователя

- запрос на доработку сразу появляется собственной bubble «Вы»;
- running/queued показывают понятный безопасный статус текущего этапа;
- завершение связано с номером созданной версии и публичным summary;
- failed/cancelled остаются рядом с тем запросом, который остановился;
- drawer «Версии» сохранён;
- после reload completed-история восстанавливается из versions и public events,
  а активный запрос — из owner-scoped run;
- running-сообщения строятся только из фиксированного словаря этапов, а
  completed summary проходит отдельный plain-language gate; системные роли,
  prompt/provider/model/payload, JSON, код, URL и raw errors в чат не выводятся.

## Почему mobile preview обрезался

Клиент считал scale только от ширины и затем принудительно записывал canvas
`min-height` не меньше 620 px. Но workbench имеет высоту одного viewport и
`overflow: hidden`, поэтому нижняя часть iframe оказывалась за экраном. После
первой правки живой Chromium дополнительно показал, что 160-миллисекундный
transition transform временно возвращал устройство к слишком крупному размеру.

Теперь scale равен минимуму из ограничений ширины и высоты, inline `min-height`
не создаётся, `ResizeObserver` пересчитывает обе оси, а mobile transform
применяется без промежуточного переполнения.

## Что пока не заявляем

- production deployment;
- изменение самого RFN-виджета или его публикации;
- изменение биллинга, Яндекс.Директа или production nginx.

## Возможный сюжет

Раньше владелец сайта видел свою просьбу только в истории версий, а слева в
чате оставалась общая фраза. Теперь Studio отвечает как настоящий рабочий
диалог: вот что попросили, вот что происходит, вот новая версия и конкретный
результат. Заодно тот же виджет полностью помещается даже на небольшом телефоне.
