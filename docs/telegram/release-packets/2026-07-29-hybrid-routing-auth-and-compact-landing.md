# Release packet: гибридный AI-маршрут и устойчивый вход

Дата: 2026-07-29
Статус: опубликовано на production; готово к редактуре

## Крючок

Kaigo больше не просит одну модель делать всё. GPT-5.5 принимает творческие и
контрольные решения, а GLM-5.2 собирает и исправляет код виджета. Так мы сохраняем
сильную идею GPT и используем GLM как более быстрый исполнитель.

## Что изменилось

- На лендинг вернулся главный тезис для бизнеса: «Через 10 минут вы сможете
  сказать: наш бизнес использует AI».
- Первый результат по-прежнему можно получить бесплатно после входа.
- Лендинг адаптирован к Windows 125%: эффективный экран 1536×960 больше не
  сталкивает карточки процесса с макетом сайта.
- GPT-5.5 отвечает за три направления, независимый выбор, план композиции,
  визуальный вердикт и code review.
- GLM-5.2 отвечает за HTML/CSS/JavaScript, брендовый слой, диалог, анимации и
  автоматические исправления.
- Gemini временно сохраняется только там, где модели нужно видеть скриншоты
  исходного сайта или готового виджета.
- Ошибка OAuth-провайдера больше не превращается в белый экран или HTTP 500;
  пользователь видит понятное сообщение и кнопку повторного входа.

## Проверенные факты

- Frontend unit: 161 тест.
- Landing browser E2E: compact, desktop, mobile, reduced motion и accessibility.
- OAuth: 25 сценариев, включая удалённый черновик и недоступный провайдер.
- Гибридный worker: Qwen Code 0.21.0 заранее установлен в Docker image; runtime
  не использует `npx` и не загружает пакеты из сети.
- В приватном аудите нет текста prompt, exception message и API-ключей.
- Production работает на commit `a05ce5a`: приложение и worker запущены,
  PostgreSQL здоров, публичный `/api/health` отвечает `200`.
- Встроенный браузер проверил реальный лендинг при 1536×960: горизонтального
  переполнения и наложения карточек на макет нет.

## Что пока не утверждать

- Реальный вход через Яндекс или Google ещё не проверен без OAuth client ID и
  secret владельца приложения.
- Это не финальная экономика маршрута: после первого публичного прогона нужно
  сравнить время, стоимость, количество repairs и визуальные оценки по ролям.
- Скриншоты пока анализирует Gemini, потому что текущий AgentRouter-клиент
  настроен только на текст.
