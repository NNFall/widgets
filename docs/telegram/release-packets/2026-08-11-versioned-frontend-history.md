# Семь версий Kaigo теперь можно открыть рядом

Дата: 2026-08-11

Статус: развёрнуто и проверено на `kaigo.space`.

## Что изменилось для пользователя

- На <https://kaigo.space/frontend/> собрана хронология из семи заметных
  этапов интерфейса. Не нужно искать старые commits или вспоминать отдельные
  preview-домены.
- У каждого этапа есть постоянная ссылка. Где версия содержит разные
  поверхности, отдельно доступны лендинг, Studio и product tour.
- Studio v1, v2 и v3 сразу открывают рабочее пространство с чатом,
  предпросмотром и историей версий. Промежуточный список проектов пропущен.
- Старые сборки действительно соответствуют выбранным commits: каждый frontend
  собирается отдельно со своим versioned base, после чего release переключается
  атомарно.
- Текущий сайт не заменялся архивом. Главная и рабочая `/studio` продолжают
  обслуживаться прежним production release.

## Что проверено

- Индекс, все корневые versioned-ссылки, три Studio и два tour отвечают HTTP
  200. `/frontend` возвращает 308 на канонический адрес `/frontend/`.
- Встроенный браузер открыл все ключевые поверхности. Сломанных изображений,
  предупреждений и ошибок в консоли нет.
- На mobile 390 × 844 индекс, Studio v3 и tour v7 не создают горизонтального
  переполнения.
- В v7 остаются три этапа; автоматическое листание включено и подтверждено
  переходом `3 → 1`.
- До и после подключения `/` и `/studio` имеют один и тот же SHA-256. Это
  подтверждает, что текущий frontend не был подменён архивом.
- Архивный API изолирован от production: production cookies и authorization
  не передаются, `Set-Cookie` от preview скрывается, API redirects остаются в
  preview namespace.
- 8 тестов transformer/deployment-контракта, JS syntax checks, Bash syntax
  check, семь TypeScript-проверок и семь production Vite-сборок прошли.

## Почему раньше был sslip.io

`studio.5-129-236-90.sslip.io` использовался как отдельный безопасный preview:
он позволял показать незавершённый frontend, не менять основной домен и не
касаться production checkout. Для постоянного архива это уже неудобно, поэтому
проверенные версии перенесены на канонический домен `kaigo.space` под отдельный
путь `/frontend/`.
