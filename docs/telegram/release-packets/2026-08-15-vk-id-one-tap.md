# VK ID One Tap в окне входа Kaigo

Дата: 2026-08-15

Статус: реализовано и проверено локально; production-релиз и ручной вход через
реальный VK-аккаунт ещё не зафиксированы.

## Что добавлено

- В существующем окне авторизации появился третий способ входа — официальный
  VK ID One Tap. Google и Яндекс сохранены.
- Выбран нейтральный однострочный вид кнопки «Войти с VK ID»: без текста
  «Продолжить как …» и без дополнительной VK-кнопки внутри виджета.
- При недоступности iframe остаётся обычная ссылка VK ID, поэтому сбой виджета
  не блокирует вход и не скрывает другие способы авторизации.
- Google и Яндекс разблокируются сразу после завершения короткого VK bootstrap;
  это убирает гонку, при которой поздний ответ VK мог сбить уже выбранный вход.
- Черновик сайта продолжает принадлежать той же браузерной сессии и после VK-
  входа открывается как проект по общему сценарию Kaigo.

## Как устроена безопасность

- Используется authorization code flow с PKCE, одноразовым `state`, коротким
  сроком действия и существующей browser binding-проверкой.
- Сервер получает и проверяет обязательный VK `device_id`, сам обменивает код и
  читает профиль. Токены VK не сохраняются во frontend.
- Совпадение VK email с существующим Google/Яндекс-профилем не объединяет
  аккаунты автоматически: вход определяется стабильным VK user id, а при
  конфликте пользователь получает безопасное предложение войти прежним
  способом. VK email также не даёт доступ к административному allowlist.
- Kaigo использует только публичный numeric App ID. Защищённый и сервисный
  ключи не нужны, не добавлены в конфигурацию и не попали в Git.
- CSP разрешает только соединение и iframe `https://id.vk.ru`. Скрипты остаются
  self-hosted; unpkg, MyTracker и wildcard не разрешены.

## Что проверить после выпуска

1. В анонимной Studio видны Google, Яндекс и одна синяя строка VK ID.
2. `/api/auth/session` возвращает provider `vk`.
3. Bootstrap создаёт одноразовую транзакцию и не кэшируется.
4. Нажатие VK открывает официальный `id.vk.ru`.
5. Владелец вручную завершает один реальный вход и подтверждает возвращение в
   Studio/привязанный проект. Без этого последний шаг нельзя считать доказанным.

## Сюжет для ролика

«В Kaigo теперь можно войти не только через Яндекс и Google, но и через VK ID.
Я оставил официальную короткую кнопку без лишнего “Продолжить как”, а сам вход
не доверил браузеру: одноразовый код проверяет сервер, и даже сохранённый до
авторизации сайт не теряется».
