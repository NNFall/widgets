# Release packet: Kaigo не спрашивает одного критика дважды

Статус: техническое улучшение готово; цифры production-ускорения будут добавлены после следующего контрольного прогона.

## Короткий факт

Раньше при повторной визуальной проверке Kaigo мог снова вызывать всех трёх критиков, даже если два уже успешно ответили по тем же кадрам. Теперь готовые ответы сохраняются, повторно вызывается только сбойная роль, а независимый судья всё равно перепроверяет общий вывод.

## Возможный заголовок

**Два AI-критика уже всё проверили. Зачем платить им второй раз?**

## Черновик поста

Сегодня убрали один довольно дорогой повтор внутри Kaigo.

После сборки виджета три независимых AI-критика смотрят desktop и mobile кадры: один проверяет диалог, второй — бренд и анимации, третий — придирается как сложный клиент. Затем отдельный судья собирает вывод.

Если судья просил ещё одну попытку по тем же кадрам, раньше все три критика могли запускаться заново. Теперь успешные ответы сохраняются, повторяется только сбойная роль, а судья ещё раз проверяет итог.

В тесте это уменьшило prompt-часть повторной попытки на 43,4%. На реальном прогоне Simple Coffee такой повтор стоил почти пять центов и около половины минуты ожидания. Следующий live-прогон покажет фактическую экономию уже в production.

## Не писать как завершённое

- Не утверждать, что вся генерация стала быстрее на 28,8 секунды: это ожидаемая экономия конкретного повторного комитета.
- Не утверждать, что production-экономия уже измерена до нового контрольного запуска.
- Не говорить, что визуальная проверка стала мягче: quorum и повторный судья сохранены.
