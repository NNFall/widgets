# Release packet: Kaigo перестал принимать повреждённые токены за нулевой расход

Дата: 2026-08-02
Статус: реализовано и проверено локально; ещё не развёрнуто

## Крючок

AI-провайдер может вернуть ответ, но передать повреждённую статистику токенов.
Раньше такой счётчик мог незаметно стать нулём. Теперь Kaigo останавливает такой
ответ, сохраняет достоверную часть расхода и не приписывает вызову модель, которую
провайдер сам не подтвердил.

## Что изменилось

- Учитываются cache-токены AgentRouter и Gemini.
- Сохраняется фактически подтверждённая модель, а не имя из настроенного маршрута.
- Повреждённые token buckets больше не маскируются нулями.
- При ошибке сохраняются корректные токены текущей и предыдущих попыток.
- Неизвестная денежная стоимость остаётся неизвестной, а не превращается в `$0`.

## Проверенные факты

- Финальный gate: `132 passed`.
- Независимые spec- и quality-review: PASS.
- Ruff, compileall и проверка diff прошли.

## Что пока не утверждать

- SQL ledger ещё не получает все новые поля: это следующий технический срез.
- Обновление ещё не развёрнуто в production.
- Новый платный live-прогон не выполнялся.
