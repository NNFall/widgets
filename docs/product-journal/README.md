# Журнал продукта Kaigo

Это внутренняя хронология проверенных изменений проекта. Журнал нужен, чтобы
техническая и редакторская задачи Codex имели общий источник фактов без чтения
всей переписки.

## Когда обновлять

Запись добавляется после значимого результата:

- новая или заметно изменённая пользовательская возможность;
- развёртывание с проверкой;
- завершённый показательный прогон;
- изменение моделей, архитектуры или качества проверки;
- измеримый результат;
- обнаруженное ограничение, важное для аудитории.

Обычные команды, внутренние переименования и незавершённые попытки сюда не
попадают.

## Формат записи

```markdown
## YYYY-MM-DD — Короткое название

Статус: прототип | проверено локально | развёрнуто | проверено пользователем

Что изменилось:
- ...

Что увидит пользователь:
- ...

Доказательства:
- commit, тест, run ID, скриншот или ссылка

Ограничения:
- ...

Потенциал для публикации:
- самостоятельный пост | часть дайджеста | не публиковать
```

Новые месяцы создаются отдельными файлами `YYYY-MM.md`. Старые записи не
переписываются ради красивой истории: последующие уточнения добавляются новой
датой.
