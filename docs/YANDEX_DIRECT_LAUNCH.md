# Первый запуск Яндекс.Директа и воронка Kaigo

Дата проверки: 2026-08-20.

## Ссылка для первого объявления

Для первого теста используйте один фиксированный адрес:

```text
https://kaigo.space/?utm_source=yandex&utm_medium=cpc&utm_campaign=first-widget&utm_content=hero
```

Kaigo сохраняет только пять безопасных UTM-меток. Полные URL, поисковые
запросы, введённые адреса сайтов, email и IP-адреса в аналитическую воронку не
записываются.

## Где смотреть результат

- все источники: <https://kaigo.space/operator/funnel>;
- только Яндекс.Директ:
  <https://kaigo.space/operator/funnel?source=yandex>;
- машинный JSON для дальнейшей выгрузки:
  <https://kaigo.space/api/operator/funnel?source=yandex>.

Страницы доступны только подтверждённому операторскому аккаунту Kaigo. В
интерфейсе можно выбрать период до 366 дней. Сырые данные автоматически
удаляются через 90 дней.

## Что считается

Основная последовательность:

1. посетитель открыл лендинг;
2. после авторизации создан проект;
3. генерация запущена;
4. получен бесплатный результат;
5. виджет опубликован.

Отдельно, без искусственного выстраивания в одну линию, показываются:

- долистывание до финального предложения;
- нажатие перехода в Studio;
- фактический вход в Studio;
- отправка ссылки на сайт;
- начало и завершение авторизации;
- активация Founder Pilot;
- начало платного оформления и подтверждение оплаты.

Founder и платный путь намеренно не складываются в одну обязательную цепочку:
участник Founder Pilot может опубликовать виджет без оплаты. Поэтому отчёт не
показывает ложные `0%` между оплатой и публикацией.

Единица подсчёта — анонимный путь браузера, а не IP и не человек. Один путь
сохраняется в серверной сессии до 14 дней, поэтому это корректная продуктовая
метрика для сравнения этапов, но не паспортно точный подсчёт людей. Общий IP
офиса или мобильного оператора не склеивает разных посетителей.

## Что настроить в Яндекс.Директе

1. Создать кампанию и объявление.
2. В поле ссылки указать адрес выше без изменений.
3. После запуска открыть отчёт с `source=yandex` и сравнивать количество путей
   на каждом этапе.
4. Для нового объявления менять только заранее согласованную метку
   `utm_content`; первый тест использует `hero`.

Яндекс официально поддерживает UTM-метки в ссылках объявлений и рекомендует
указывать как минимум `utm_source`, `utm_medium` и `utm_campaign`:
<https://yandex.ru/support/direct/ru/statistics/url-tags>.

## Нужна ли Метрика прямо сейчас

Для первого небольшого трафикового теста — нет: собственная воронка Kaigo уже
покажет, где посетители теряются, а в приложение не добавляется сторонний
трекер.

Метрика потребуется перед автоматической оптимизацией кампании по конверсиям,
ретаргетингом и сверкой отчётов внутри интерфейса Директа. Тогда порядок такой:

1. создать счётчик Метрики;
2. отдельно согласовать установку её клиентского тега и изменение CSP;
3. создать цели для нужных действий;
4. вызвать официальный `reachGoal` только на подтверждённых действиях;
5. привязать счётчик и выбрать цели в настройках кампании.

Официальные инструкции:

- связь Директа и Метрики:
  <https://yandex.ru/support/direct/ru/statistics/metrika>;
- JavaScript-цели `reachGoal`:
  <https://yandex.ru/support/metrica/ru/objects/reachgoal>;
- выбор приоритетных целей:
  <https://yandex.ru/support/direct/ru/strategies/priority-goals>.

До появления ID счётчика Kaigo не добавляет фиктивный тег Метрики и не
отправляет события третьей стороне.
