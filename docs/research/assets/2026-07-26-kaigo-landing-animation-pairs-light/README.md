# Светлые пары анимации первого экрана Kaigo

Серия состоит из пяти концепций, по два кадра в каждой: состояние до запуска
анимации и состояние после завершения сканирования. Это не десять независимых
макетов, а пять последовательностей `before → after`.

## Общий сценарий

1. Слева постоянно остаются логотип, B2B-оффер, пояснение и поле URL.
2. Справа показан один условный действующий сайт нейтрального серого цвета.
3. По сайту медленно проходит линия, плоскость или линза сканирования.
4. Уже пройденная область получает аккуратные фирменные акценты.
5. Внутри сайта появляется компактный AI-виджет с настоящей структурой чата.
6. Следом проявляются только три преимущества: знает бизнес, повторяет стиль
   сайта, отвечает клиентам круглосуточно.
7. Launcher даёт один спокойный пульс и остаётся в состоянии покоя.

Левая часть между двумя кадрами не должна перестраиваться. В реальном
интерфейсе меняется только демонстрационная сцена справа.

## Концепции

1. **Фронтальный скан** — самый прямой и понятный вариант:

2. **Перспективная плоскость** — сайт показан как тонкий лист под небольшим
   углом: [до](02a-perspective-scan-before.png) →
   [после](02b-perspective-scan-after.png).
3. **Диагональная волна** — сканер движется из левого верхнего угла в правый
   нижний: [до](03a-diagonal-scan-before.png) →
   [после](03b-diagonal-scan-after.png).
4. **Панорамный экран** — вертикальная линия проходит по слегка изогнутому
   сайту слева направо: [до](04a-panoramic-scan-before.png) →
   [после](04b-panoramic-scan-after.png).
5. **Site Lens** — авторское развитие идеи: сайт проходит через спокойную
   аналитическую линзу: [до](05a-site-lens-before.png) →
   [после](05b-site-lens-after.png).

## Ограничения серии

- Текст внутри растровых референсов нужен для проверки иерархии, а не для
  прямого переноса в production.
- Это desktop-кадры `16:9`; mobile-композиция будет проектироваться после
  выбора одной механики.
- Анимация пока описана двумя ключевыми состояниями. Промежуточные кадры,
  easing и точная длительность появятся на этапе motion-спецификации.
