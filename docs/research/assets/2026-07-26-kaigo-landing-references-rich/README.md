## Первичная рекомендация

Для дальнейшей разработки стоит разобрать по элементам варианты `01`, `05` и
`07`:

- из `01` взять иерархию и наглядный рабочий чат;
- из `05` взять дружелюбную продуктовую ясность;
- из `07` взять сильную типографику и узнаваемый визуальный язык.

Варианты `03` и `08` полезно сохранить как отдельное premium-направление.
