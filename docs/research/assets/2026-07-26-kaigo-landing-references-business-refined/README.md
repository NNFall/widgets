# Уточнённые B2B-референсы первого экрана Kaigo

Шестая серия развивает выбранные пользователем концепции: трансформацию сайта,
объёмную ленту и раскрывающийся генеративный объект.

Что изменилось:

- оффер везде обращён к бизнесу;
- финальным продуктом назван именно `AI-виджет`;
- исходный сайт, этап анализа и готовый результат визуально различимы;
- крупные карточки получили полноценные объяснения;
- для каждой концепции заранее задана воспроизводимая палитра с HEX-кодами;
- motion описывает создание продукта: сканирование, сборку и открытие чата.

## Концепции

1. [Понятное «до/после»](01-clear-before-after.png) — исходный сайт сверху,
   тот же сайт с открытым AI-виджетом снизу.
2. [Призматическая трансформация](02-prism-transformation.png) — единый экран
   постепенно раскрывает знания, стиль и готового консультанта.
3. [B2B-лента](03-business-ribbon.png) — три содержательных этапа связаны
   объёмной лентой; оффер заканчивается фразой «наш бизнес использует AI».
4. [Конвейер продукта](04-conveyor-story.png) — сайт проходит через анализ и
   превращается в виджет для консультаций и заявок.
5. [Widget iris](05-widget-iris.png) — знания, стиль и задача собираются вокруг
   работающего виджета.
6. [Сборка виджета](06-widget-assembly.png) — контент, бренд и клиентские
   вопросы сходятся в одном персональном консультанте.
7. [Живой blueprint](07-living-blueprint.png) — схема сайта превращается в
   рабочий AI-интерфейс.
8. [Site lens](08-site-lens.png) — сайт проходит через три аналитических слоя и
   выходит с открытым виджетом.

- Lapis/copper: `#081849`, `#213885`, `#ECDFD2`, `#B87333`.
- Deep teal/sky/lime: `#094542`, `#212161`, `#85D5F6`, `#BCFB89`.
- Charcoal/coral: `#1A1A1A`, `#2B384C`, `#ABE2F4`, `#E35336`.
