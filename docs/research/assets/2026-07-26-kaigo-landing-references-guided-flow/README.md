# Референсы Kaigo с направляющим сценарием

Четвёртая серия первого экрана. Она развивает наиболее подходящие варианты
прошлой серии: светлый №1 и тёмный №3.

Зафиксированная композиционная идея:

1. Короткий заголовок объясняет результат, а не просто повторяет действие.
2. Одна строка уточняет индивидуальность виджета и анализ сайта.
3. Три компактных шага показывают путь пользователя.
4. Линия или стрелки визуально приводят к единственному полю URL.
5. Цветовая система почти монохромная; акцент используется только для маршрута
   и кнопки.

## Варианты

1. [Светлый горизонтальный маршрут](01-light-horizontal-flow.png) — буквальная
   последовательность из трёх карточек над вводом.
2. [Тёмно-синий горизонтальный маршрут](02-navy-horizontal-flow.png) — наиболее
   компактная тёмная версия.
3. [Светлый editorial с вертикальным маршрутом](03-editorial-vertical-flow.png).
4. [Графитовый диагональный маршрут](04-graphite-diagonal-flow.png) — шаги
   завершаются маленьким launcher.
5. [Светлый нумерованный маршрут](05-light-numbered-flow.png) — самый прямой
   вариант без декоративного preview.
6. [Тёмно-синий premium](06-navy-premium-flow.png) — схема справа ведёт к
   composer внизу.
7. [Тёплый вертикальный маршрут](07-warm-vertical-flow.png) — три узких шага
   слева от ввода.
8. [Полуночный timeline](08-midnight-timeline-flow.png) — финальная точка
   подчёркивает обещание «у нас есть AI».

Это композиционные референсы `16:9`, а не утверждённый брендбук. Следующая
итерация должна выбрать одну светлую и одну тёмную компоновку, после чего уже
уточнять типографику, реальные тексты и motion.
