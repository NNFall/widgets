# Narrative-референсы первого экрана Kaigo

Пятая серия развивает идею более насыщенного первого экрана. В отличие от
предыдущей guided-flow серии, правая часть здесь является самостоятельной
визуальной сценой, которая рассказывает историю продукта.

Общая структура:

- слева — сильный слоган и содержательное объяснение;
- справа — одна выразительная метафора создания AI-сотрудника;
- внутри сцены — три крупных шага с нормальными пояснениями;
- снизу — один широкий URL-composer;
- насыщенность создают движение, глубина и взаимодействие элементов, а не
  количество независимых секций.

## Концепции

1. [AI-сфера-проводник](01-ai-orb-guide.png) — оригинальный персонаж направляет
   внимание по трём плавающим карточкам.
2. [AI-ядро и орбита](02-ai-core-orbit.png) — сайт, анализ и результат связаны
   через центральное вычислительное ядро.
3. [Трансформация сайта](03-website-transformation.png) — исходная страница
   проходит визуальный анализ и получает рабочий чат.
4. [Редакционный карточный коллаж](04-editorial-card-collage.png) — бумажные
   поверхности и нарисованный маршрут.
5. [Ленточный AI-куратор](05-ribbon-curator.png) — абстрактная световая фигура
   раскрывает этапы процесса.
6. [Три портала](06-three-portals.png) — пользователь визуально проходит от
   сайта через анализ к готовому AI-сотруднику.
7. [Разворачивающаяся лента](07-unfolding-ribbon.png) — единая объёмная стрелка
   объединяет три насыщенные сцены.
8. [AI-ателье](08-ai-atelier-flower.png) — три лепестка «сайт, стиль, сотрудник»
   раскрывают готовый виджет в центре.

Это референсы `16:9`, а не готовые макеты. Для дальнейшей детализации особенно
перспективны №3, №6 и №8: они показывают собственную продуктовую метафору Kaigo,
а не просто набор карточек.
