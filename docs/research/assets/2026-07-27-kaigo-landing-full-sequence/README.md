# Полная последовательность лендинга Kaigo

Выбранное направление — `Perspective Orbit`: светлый кремовый фон, coral/sage
акценты, наклонённые бумажные поверхности, пунктирные траектории и выделенный
AI-виджет. Серия показывает восемь последовательных desktop-экранов будущего
лендинга.

2. [Как это работает](02-how-it-works.png) — подробные три шага от ссылки до

## Зафиксированный первый экран

Заголовок:

> Через 10 минут вы сможете сказать: наш бизнес использует AI

Header:

- `Продукт`;
- `Как это работает`;
- `Кейсы`;
- `Вопросы`;
- `Перейти в студию`.

Первый экран использует анимацию `Perspective Orbit`: сайт сканируется,
смещается вправо, три карточки появляются по траектории, затем раскрывается и
однократно подсвечивается AI-виджет.

## Примечания

- Это визуальные референсы `16:9`, а не готовые HTML-макеты.
- Текст необходимо переносить в настоящую вёрстку, а не оставлять частью
  растровых изображений.
- Header на внутренних кадрах показан только для проверки цельности; в реальной
  странице он один и может оставаться sticky.
- Mobile-версия проектируется после утверждения desktop-последовательности.
