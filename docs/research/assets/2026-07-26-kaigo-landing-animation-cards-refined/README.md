# Уточнённые анимационные пары Kaigo с карточками

Серия развивает два выбранных направления — перспективную плоскость и
панорамный экран — и добавляет один авторский вариант. Всего создано пять
концепций по два ключевых кадра: `before → after`.

## Что исправлено относительно предыдущей серии

- Обычные подписи на линиях заменены самостоятельными карточками.
- Каждая карточка содержит номер, иконку, заголовок и понятное пояснение.
- Карточки связаны направленной траекторией и продолжают движение сканера.
- Виджет выделяется отдельной рамкой, подписью и одним импульсом.
- Под заголовком сохранено полноценное объяснение услуги.
- В финальном кадре пользователь видит не только преимущества, но и процесс:
  ссылка → анализ → первый результат → проверка и подключение.

Левая часть страницы между кадрами остаётся стабильной. Перестраивается только
правая демонстрационная сцена.

## Предлагаемый порядок motion

1. `0–800 мс` — страница находится в спокойном исходном состоянии.
2. `800–2600 мс` — сканирующая линия или плоскость проходит по сайту.
3. `1800–3200 мс` — сайт получает цвет и немного смещается, освобождая место.
4. `2400–4200 мс` — карточки появляются по одной с интервалом `220–320 мс`.
5. `3800–4700 мс` — внутри сайта раскрывается чат.
6. `4300–5000 мс` — рамка виджета делает один спокойный импульс.
7. После `5000 мс` — вся композиция остаётся неподвижной; повторно пульсировать
   может только launcher, не чаще одного раза в `12–15 секунд`.

## Ограничения

- Растровый текст используется для проверки композиции. Production-копирайт
  будет переноситься в HTML, а не извлекаться из изображений.
- Карточки не должны появляться одновременно: тогда они снова превращаются в
  перегруженный статичный блок.
- На mobile перспективная плоскость и карточки потребуют отдельной вертикальной
  последовательности после выбора desktop-концепции.
