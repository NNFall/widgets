# AgentRouter: Flowwow pure-model comparison

Дата прогона: 2026-07-28. Одинаковый brief, grounded-контекст Flowwow,
контракт `chat-v1`, температура `0.9` и максимум две попытки автоматического
ремонта после серверной валидации. Каждый вариант целиком создавался одной
моделью; смешивания моделей внутри прогона не было.

| Метрика | GLM-5.2 | GPT-5.5 |
|---|---:|---:|
| Вызовов | 2 | 2 |
| Время | 511,637 с | 542,154 с |
| Входные токены | 60 593 | 39 537 |
| Выходные токены, включая reasoning | 126 635 | 15 196 |
| Thinking, диагностическая часть output | 107 295 | 643 |
| Ошибок контракта после первого вызова | 12 | 4 |
| Ошибок после ремонта | 0 | 0 |
| Расчётная стоимость | $1,123368 / 112,34 ₽ | $0,383131 / 38,31 ₽ |

Цены взяты из кабинета AgentRouter, показанного владельцем проекта:
GLM-5.2 — $6 за миллион input/output tokens, GPT-5.5 — $7. Курс для
сравнения — 100 ₽/$; итоговое списание нужно сверять по request ID в кабинете.
Thinking не прибавляется второй раз: Qwen event stream уже включает его в
`output_tokens`.

## Наблюдения

- GLM-5.2 предложил более характерную «цветочную» оболочку и после ремонта
  прошёл детерминированный контракт. В браузере панель на 1280×720 занимает
  примерно 376×413 px и не перекрывает страницу. Исходный launcher создан как
  `div`, а не как семантическая кнопка — это отдельный пробел браузерного gate,
  который детерминированная проверка пока не ловит.
- GPT-5.5 сразу допустил меньше контрактных ошибок, после одного ремонта также
  получил ноль. Launcher — настоящая кнопка, панель примерно 390×472 px,
  интерфейс яснее читается как двухсторонний чат. Визуальная идея спокойнее,
  зато семантика и рабочая структура аккуратнее.
- Оба preview вручную проверены во встроенном браузере: открытие, закрытие,
  ввод и отправка сообщения работают; runtime добавляет пользовательский ход и
  pending-состояние ответа.

## Артефакты

- `glm-5.2/artifact.json`, `glm-5.2/preview.html`, `glm-5.2/report.json`
- `gpt-5.5/artifact-attempt-1.json` — сырой результат до ремонта
- `gpt-5.5/artifact-attempt-2.json`, `gpt-5.5/preview.html`,
  `gpt-5.5/report.json` — финальный вариант

GLM-первый артефакт не был сохранён отдельным файлом, поскольку первый вызов
завершился до добавления поэтапного snapshot-механизма; его usage, request ID и
12 validation issues сохранены в финальном отчёте.
